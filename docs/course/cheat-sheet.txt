    B) Konfigurovanie ACL
Router(config)# access-list 1-99 permit|deny source-IP-address wildcard-mask [log]

Router(config)# access-list 100-199 permit|deny IP-protocol source-IP wildcard-mask [source-port]
               destination-IP wildcard-mask [dest- port] [log]

Router(config)# access-list 100-199 permit|deny tcp|udp source-IP wildcard-mask [operator-source-
                 port] destination-IP wildcard-mask [operator-dest -port] [established] [log]
  operator: lt (lower than), gt (greater than), eq (equal), neq (not equal), range (rozsah portov: 0 65535)

Router(config)# access-list 100-199 permit|deny icmp source-IP wildcard-mask destination- IP
                wildcard mask icmp type | icmp message [log]
     icmp type je číselná hodnota icmp správy
     najčastejšie sa zakazuje:ping (echo, echo-reply), redirect, unreachables, traceroute
