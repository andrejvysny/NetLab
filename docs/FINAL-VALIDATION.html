Exam-relevant corrections

  • Media and clocking. The ISR has two copper jacks, not three. Catalyst fixed 1G SFP uplinks are distinct from its 24 copper ports. Empty SFP cages reject copper cables. Serial clock state is distinct from line protocol and interface bandwidth. Double-clicks reach the actual device instead of its inspector.
  • CLI and configuration. EXEC privilege, do, aliases, help, pager state and dialogue handling were corrected. An invalid replacement or legacy startup file no longer silently applies a partial replacement. Merge/paste remain intentionally different from atomic replacement.
  • Traffic and grade. Missing DHCP service or NAT selectors no longer produce valid leases/translations. IPsec selectors respect earlier denies. A one-way HTTP path, undelivered inner packet or ineffective management restriction is not evidence of success. Telnet checks cover later VTY lines too. SNMP views and source restrictions affect the modeled MIB. Enabled link/config traps reach eligible receivers; syslog shows suppression distinctly from a delivery failure.
  • Catalyst NAT. Basic static, pool and PAT forms are modeled on eligible routed front-panel ports under the explicit Network Advantage profile. Not an ASA, ISR, or arbitrary SVI/ASIC NAT simulation.
  • QoS. Course mode accepts the handout-derived worked configuration at 18/18. Change only the WAN classifier to after encryption: only QoS fails. Apply qos pre-classify to the two active sender maps and 18/18 returns. Ethernet bandwidth metadata does not physically throttle the link. The load tool is an estimated allocation, not measured throughput.

Before the real exam

Check show version, show inventory and, on the router in privileged EXEC, show controllers serial 0/1/0 (use its actual interface number). Check clock rate ? on the DCE side. NetLab accepts the handout’s 128000; the serial NIM guide lists 125000 but not 128000. Exact acceptance or rounding on your lab’s image and NIM has not been verified.

There is no SSH login or real on-wire cryptography, SNMPv3 security, inform retry, full internal debug stream, optical transceiver, or packet-level hardware queue timing. Strict Ethernet polarity is a teaching setting, not a claim about a modern switch’s default Auto-MDIX. Newer images can differ in licensing, crypto choices and initial console setup. NetLab practice points are not the instructor’s rubric.
